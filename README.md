\# Driver Drowsiness Detection System



An AI-powered real-time driver drowsiness detection system developed using Python, OpenCV, and MediaPipe.  

The system monitors the driver's eyes and facial landmarks through a webcam and detects signs of drowsiness to help prevent accidents.



\---



\## Features



\- Real-time face and eye detection

\- Eye aspect ratio monitoring

\- Drowsiness alert detection

\- Facial landmark tracking using MediaPipe

\- Haar Cascade based face and eye recognition

\- Simple and lightweight implementation



\---



\## Technologies Used



\- Python

\- OpenCV

\- MediaPipe

\- NumPy
